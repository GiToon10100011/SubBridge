# SubBridge 위험 분석

> 근거 표시: ✅ 1차 출처 / ◐ 2차 출처·사용자 보고 / ❓ 미확인. 우선순위순.

## 2. 항목별 상세

### R1 — DRM

- **Windows**: WASAPI 루프백은 DRM으로 보호된 디지털 스트림을 허용하지 않는다고 공식 문서에 명시돼 있다. 신뢰된 오디오 드라이버가 루프백 장치의 보호 콘텐츠 캡처를 허용하지 않는다 ✅ ([MS Learn](https://learn.microsoft.com/windows/win32/coreaudio/loopback-recording)).
- **macOS**: Safari + FairPlay에서 오디오 녹음이 막힌다는 개발자 포럼 보고가 있다(단일 보고) ◐ ([Apple 포럼](https://developer.apple.com/forums/thread/816464)). WebKit 버그 코멘트(2018)에도 FairPlay로 보호된 미디어는 화면 녹화에 나타나지 않는다고 적혀 있다 ◐. ScreenCaptureKit/탭이 FairPlay 오디오를 어떻게 다루는지는 ❓.
- **브라우저 Widevine**: 영상은 검게 나와도 오디오는 녹음됐다는 OBS 사용자 보고가 있다 ◐. 공식 확인은 없다.
- **제품 정책**: 「재생 중인데 디지털 무음」이 이어지면 「보호된 오디오로 보여 캡처할 수 없음」을 안내한다. 우회 기능·우회 안내는 만들지 않는다.
- **제품 문서에 쓸 문장(초안)**: 「SubBridge는 컴퓨터가 재생하는 소리를 허용된 범위에서 받습니다. 일부 서비스는 보호된 오디오를 막으며, 이 경우 SubBridge는 동작하지 않습니다.」

### R2 — 번역 품질

- 후보 모델은 Qwen3.5, Gemma 4, TranslateGemma 등 (라이선스는 TECH_STACK §5). 일본어 → 한국어 직접 비교 벤치는 찾지 못했다 ❓ → 평가셋으로 직접 측정한다.
- 품질 기준: 평균 ≥ 3.5/5, 존대 일치 ≥ 90% (초기 목표, Phase 0에서 조정).
- 완화책: 실시간은 소형, 최종 패스는 대형. 최종 결과를 사용자가 쉽게 고치는 편집기가 품질 부족의 안전망이다.

### R3 — 지연·자원 경합

- whisper.cpp 스트리밍 지연 실측치는 확인하지 못했다 ❓. whisper_streaming의 3.3초(논문)와 my-translator의 2~3초 ◐가 참고 범위다.
- ASR과 LLM이 같은 GPU를 쓸 때의 경합은 ❓.
- 모니터링: 단계별 타임스탬프를 항상 기록하고, 진단 패널에서 p50/p95를 볼 수 있게 한다.

### R4 — 타임라인 정합

SubBridge는 영상의 재생 위치를 모른다. 영상을 일시정지·탐색하거나 광고·인트로 건너뛰기가 있으면 캡처 시간과 영상 시간이 어긋난다. 재생 속도가 1.0배가 아니어도 어긋난다.

- 정의: SRT 시간 = 캡처가 진행된 시간. SubBridge를 일시정지한 구간은 타임라인에서 뺀다.
- 완화: 편집기에서 싱크 맞추기·전체 이동·지점별 간격 삽입/삭제를 제공한다. 시작 전에 1.0배속·처음부터 재생을 안내한다.
- 자동 보정 불가: 재생 속도 변경, 중간 되감기.
- 내보낸 SRT를 외부 플레이어에서 쓸 때 해당한다. SubBridge 재생 모드가 영상 위치를 스스로 추정하는 문제는 R14.

### R5 — 데이터 손실

- 청크 단위 저장, 약 2초마다 fsync → 손실 ≤ 2초(목표).
- SQLite WAL + `synchronous=NORMAL`은 앱 크래시는 견디고 전원 차단 시 마지막 트랜잭션을 잃을 수 있다. 상태 전이·완료 처리에는 `FULL`.
- 검증: kill -9 자동 테스트를 Phase 1부터 돌린다.

### R6 — 환각

PIPELINE §4. 표시하되 자동 삭제하지 않는다 (진짜 대사를 지우는 오류가 더 나쁘다).

### R7 — 장치 변경

이어폰 연결/해제로 기본 출력이 바뀌면 탭/집합 장치가 끊길 수 있다 ❓. 속성 리스너로 감지해 재구성하고, 실패하면 Paused + 알림.

### R9 — 법·약관

- 이 문서는 법률 자문이 아니다. **공개 배포 전에 법률 검토를 받는다.**
- 설계로 줄이는 것: DRM 우회 없음, 영상 저장 없음, 번역 자막 공유 기능 없음, 데이터를 외부로 보내지 않는 로컬 기본값.
- OTT 이용 약관이 녹화·캡처를 금지할 수 있다. 사용자 책임 고지를 온보딩에 둔다.
- 클라우드 Provider를 추가하면 오디오/텍스트가 외부로 나간다 → 명시적 동의와 BYOK로 제한.

### R10 — 모델 라이선스

- Hunyuan-MT 계열은 EU·영국·대한민국을 적용 지역에서 제외한다 ◐ → 한국에서 쓰면 무라이선스. **제외.**
- NLLB-200은 CC-BY-NC → 상업 배포 시 제외.
- TranslateGemma는 Gemma 이용약관: 금지 정책을 하위 사용자에게 전달해야 한다 ◐.
- 모델마다 라이선스를 레지스트리에 저장하고 UI에 표시한다. 배포 범위(Q1)가 정해지면 허용 목록을 확정한다.

### R11 — macOS 권한

- 시스템 오디오 녹음 권한 상태를 확인하는 공개 API가 없고, 거부돼도 Core Audio는 오류 없이 무음 버퍼를 준다 ✅.
- ScreenCaptureKit은 Sequoia에서 매달 재승인을 요구한다 ◐ — 탭 우선 선택의 이유.
- 온보딩에서 테스트 소리로 확인하고, 실행 중에는 무음 감지로 안내한다.

### R12 — 자체 번역 엔진 (Q1, 형태 미정)

- 엔진이 **로컬 모델**이면 기반 모델의 라이선스를 상속한다 (TECH_STACK §5·§8: Hunyuan 계열 제외, NLLB 제외, Gemma 계열은 이용약관 조건). 배포 범위(Q1) 확정 전에는 Apache-2.0 계열(Qwen3.5, Gemma 4 ◐)을 기본 후보로 둔다.
- 엔진이 **서버/API**이면 원칙 5(로컬 기본)와 충돌한다 → 옵트인 + 전송 내용 고지 (R9).
- **학습 데이터**: 드라마 대사와 그 번역은 저작물일 수 있다. 사용자 수정본(EditLog)을 학습에 쓰는 것은 법·약관 검토 후 별도로 결정한다. 기본값은 수집·전송하지 않는 것이다.
- **평가**: 평가 하네스(Phase 0 평가셋)를 엔진보다 먼저 만든다. 엔진 교체는 점수로 판단한다.
- **완화**: TranslationProvider 계약(PIPELINE §6.1)을 지키면 엔진 교체가 파이프라인에 영향을 주지 않는다.

### R13 — 앱 단위 캡처의 한계 (Q6)

- Core Audio 탭은 프로세스 단위 API다. 브라우저에서 소리를 내는 프로세스가 본체인지 헬퍼인지는 브라우저마다 다를 수 있다 ❓.
- 탭 하나만 골라 캡처할 수 없다. OTT를 보는 브라우저에서 다른 탭이 소리를 내면 섞인다 → 선택 화면과 온보딩에 안내한다.
- 대상 앱이 종료·재시작되면 프로세스 ID가 바뀐다 → 번들 ID로 다시 찾고, 실패하면 Paused.
- 검증: Phase 0 체크리스트 ① (IMPLEMENTATION_PLAN §2).

### R14 — 재생 모드 자동 싱크의 실현성 (Q19)

- 사용자는 자동 싱크를 기본으로 원한다(수동만으로는 불편). 그러나 **어느 방식도 실현 가능성이 확인되지 않았다** ❓ — 구현 사례나 측정 결과를 찾지 못했다.
- 실패 가능성: 광고 삽입·버전 차이·더빙으로 소리가 달라짐 / 조용하거나 대사가 반복되는 장면에서 위치를 못 찾거나 잘못 찾음 / 영상 일시정지를 소리로 구분하기 어려움 / 보호된 오디오는 아예 들리지 않음 (R1).
- 잘못된 위치에 자막을 확정하는 것(오락)이 못 찾는 것보다 나쁘다 → 락 조건을 엄격히 둔다 (PIPELINE §10).
- 비용: 지문 방식은 가볍지만 지문 저장이 필요하고(Q20), ASR 방식은 재생 내내 ASR이 돌아간다.
- 폴백: 수동 시작·보정. 사용자와 합의한 대로, 자동이 쓸 만하지 않다고 판명되면 **수동을 기본으로 바꾸고 보고**한다.
- 검증: Phase 0 ⑧, Phase 5.5 완료 조건.

## 4. 법적 고지 초안 (온보딩·정보 창)

> SubBridge는 사용자의 컴퓨터에서 재생되는 소리를 사용자가 직접 요청한 범위에서 받아 자막을 만드는 도구입니다.
> 일부 서비스는 보호된 오디오의 캡처를 막으며, SubBridge는 이를 우회하지 않습니다.
> 서비스의 이용 약관과 저작권 법령을 지키는 것은 사용자의 책임입니다.
> 번역 자막은 원저작물의 2차적저작물일 수 있으므로 공유·배포 전에 권리 관계를 확인하세요.
> 오디오는 이 컴퓨터에서만 처리되며, 작업 완료 시 임시 오디오가 삭제됩니다.

(검토 전 초안이며 법률 자문이 아니다. 클라우드 Provider를 켜면 별도 고지가 필요하다.)

## 5. 위험 재평가 시점

- Phase 0 종료 시: R1, R2, R3, R7, R11의 가능성과 영향을 실측으로 다시 매긴다.
- Q1(배포 범위) 확정 시: R9, R10 재평가.
- Phase 6 종료 시: 전체 재검토.
