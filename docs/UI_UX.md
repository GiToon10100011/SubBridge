# SubBridge UI/UX

> 화면 흐름과 동작 규칙의 초안이다. 시각 디자인(색·글꼴·레이아웃 상세)은 구현 단계에서 정한다.
> 참고: TeroSubtitler의 편집 UX (파형, 구간 편집), Vibe의 모델·내보내기 흐름. 초보자가 쓰기 쉬워야 한다.

## 1. 전체 흐름

```text
온보딩(권한·모델) → 새 프로젝트(언어·소스) → 캡처(+오버레이) → Processing → 편집 → 내보내기 → 작업 완료
                         ▲                                         │
                         └──── 최근 프로젝트 열기 / 중단 복구 ──────┘
```

## 2. 온보딩

1. **환영 + 사용 범위 고지**: 오디오만 처리하며 영상은 저장하지 않는다. DRM으로 보호된 오디오는 캡처할 수 없을 수 있다. 번역 자막을 공유하지 않도록 안내한다 (법률 자문이 아님).
2. **하드웨어 점검**: RAM·칩을 읽어 ASR/번역 모델을 추천한다 (8GB / 16GB / 32GB+ 프로파일).
3. **모델 다운로드**: 크기·라이선스·진행률·체크섬 검증. 모델마다 라이선스를 표시한다.
4. **오디오 권한**: macOS는 권한 상태를 확인하는 공개 API가 없다 ✅. 「테스트 소리」를 재생해 실제로 소리가 들어오는지 확인하는 방식으로 안내한다. 무음이면 시스템 설정으로 가는 버튼과 단계별 안내를 보여 준다.

## 3. 캡처 화면

- **소스 선택 (Q6: 앱 단위)**: 지금 소리를 내는 앱(브라우저·플레이어) 목록에서 고른다. SubBridge 자신의 소리는 항상 제외한다. 브라우저는 탭 단위로 나눌 수 없어 같은 브라우저의 다른 탭 소리가 섞일 수 있다 — 선택 화면에 안내한다. 「시스템 전체」는 MVP에 없다.
- **제어**: 시작 · 일시정지 · 재개 · 종료. 경과 시간(일시정지 구간 제외), 입력 레벨 미터, 디스크 사용량, 모델 상태(ASR/번역).
- **실시간 목록**: 최근 확정 자막이 위로 흐른다. 잠정 결과는 흐리게.
- **지연 중 표시**: 따라잡기 모드일 때 「일부 구간은 종료 후 보강됩니다」.
- **종료 확인**: 「종료하고 처리」 / 「일시정지로 두기」.
- **시작 전 안내**: 영상을 처음부터 **1.0배속**으로 재생하면 자막 시간이 영상과 가장 잘 맞는다. 되감기·건너뛰기가 많으면 편집기의 싱크 맞추기로 보정한다. 캡처를 먼저 시작하고 영상을 재생하는 순서를 권한다.

### 무음·DRM 안내
재생 중인데 디지털 무음이 N초 이어지면 다음 순서로 안내한다.
1. 영상이 실제로 재생 중인지 / 음소거가 아닌지 / 올바른 앱을 골랐는지.
2. 권한이 있는지 (테스트 소리 확인).
3. 「보호된 오디오로 보여 캡처할 수 없습니다.」 — **우회 방법은 안내하지 않는다.**

## 4. 오버레이

| 항목 | 동작 |
|---|---|
| 표시 모드 | 원문+번역 / 원문만 / 번역만 (단축키로 순환) |
| 스타일 | 글자 크기, 색, 배경 투명도, 윤곽선 |
| 위치 | 드래그 이동 + 화면 가장자리 스냅. 위치는 기억한다 |
| 항상 위 | 켜기/끄기. 마우스 통과 모드(영상 조작을 방해하지 않음) |
| 표시/숨김 | 전역 단축키 |
| 잠정 결과 | 흐리게 표시, 확정되면 선명하게 |
| 번역 대기 | 원문 먼저, 번역은 도착하면 채움 |

제약:
- macOS 전체화면 영상 위 표시는 ❓ (Phase 0 검증, `fullScreenAuxiliary`).
- Linux Wayland는 「항상 위」가 불가능하다 ✅ → 일반 창으로 대체하고 WM 규칙을 안내한다.

## 5. Processing 화면

- 단계별 진행률: 최종 인식 → 분절 → 번역. 예상 남은 시간.
- 「건너뛰고 실시간 결과로 편집」 (Q7 확정: 기본은 기다린다, 급하면 건너뛰기).
- 앱을 닫아도 Job은 체크포인트에서 이어진다는 안내.

## 6. 편집기

```text
┌──────────────────────────────────────────────────────────┐
│ [재생 ▶ 구간반복 ⟲]  00:12:34 / 01:02:11     내보내기 ▾ │
├──────────────────────────────────────────────────────────┤
│ 파형 타임라인 (줌, 자막 구간 표시, 드래그로 경계 조정)    │
├───────────────────────────┬──────────────────────────────┤
│ 자막 목록 (가상 스크롤)    │ 선택 줄 편집                  │
│ # 시간   원문  번역  상태  │ 원문 [..........]            │
│ 1 00:01  ...   ...   ●    │ 번역 [..........]            │
│ 2 00:04  ...   ...   ✎    │ 시작 [..] 끝 [..] 분할 병합   │
│ ...                       │ [선택 구간 재번역]            │
└───────────────────────────┴──────────────────────────────┘
```

| 기능 | 동작 |
|---|---|
| 행 클릭 | 해당 구간 오디오를 바로 재생 |
| 구간 반복 | 선택한 줄을 샘플 단위로 반복 (Rust 재생 엔진) |
| 원문/번역 편집 | 인라인 편집, 입력 즉시 저장(트랜잭션) |
| 시간 편집 | 숫자 입력 + 파형 드래그. 겹침 경고 |
| 분할/병합 | 커서 위치에서 분할, 인접 줄 병합 |
| 수정 상태 | 기계 / 수정됨(✎) / 저신뢰 / 환각 의심 / 번역 오래됨(stale) 아이콘 |
| 선택 구간 재번역 | 여러 줄 선택 → 재번역. `user_edited` 줄은 덮어쓰기 전 확인 |
| 싱크 맞추기 | 한 줄을 고르고 실제 영상 시간을 입력하면 전체 이동 값을 계산한다. 지점별 간격 삽입/삭제도 제공 |
| 필터 | 저신뢰 / 환각 의심 / 음악 / 수정됨 |
| Undo/Redo | EditLog 기반 |
| 내보내기 배지 | 「내보내지 않음」 / 「최신」 / 「내보낸 뒤 수정됨」 |

오디오가 삭제된 프로젝트(Completed 이후)에서는 재생·구간 반복·재전사 버튼이 꺼지고 이유를 표시한다. 텍스트 편집은 계속 가능하다.

## 7. 내보내기

- 종류: 원문 / 번역문 / 이중 자막. 형식: SRT (MVP), VTT (v0.2).
- 내보내기 미리보기에 첫/마지막 큐의 시간과 적용된 전체 이동 값을 보여 준다.
- 이중 자막은 한 큐에 두 줄(원문/번역)을 일반 텍스트로 쓴다. 스타일 태그는 기본으로 넣지 않는다 (플레이어마다 렌더링이 다르다).
- 옵션: UTF-8(BOM 선택), 줄바꿈, 이중 자막의 위/아래 순서.
- 내보내기 후 안내: 「내보내도 오디오는 삭제되지 않습니다.」
- 품질 검사(v0.2): 줄당 글자 수, CPS, 최소·최대 표시 시간, 겹침.

## 8. 작업 완료

「작업 완료」는 내보내기와 **별개의 버튼**이다.

확인 창 내용:
- 임시 오디오 N MB가 삭제되며 되돌릴 수 없다 `[결정 대기: Q9]`.
- 자막 프로젝트는 보존되고 계속 편집할 수 있다.
- 마지막 내보내기가 현재 내용보다 오래됐다면 경고한다.

완료 조건 미충족 시(진행 중 Job, 무결성 검사 실패) 버튼을 비활성화하고 이유를 보인다.

## 9. 중단 복구

앱을 시작할 때 Interrupted/Paused/Processing 프로젝트가 있으면 알려 준다.
- 「이어서 녹음」 (새 세션으로 이어짐) / 「여기까지로 마치고 처리」 / 「나중에」.
- 복구된 구간과 손실 가능 구간(최대 flush 간격)을 표시한다.

## 10. 오류 문구 원칙

- 무엇이 일어났는지 / 데이터가 안전한지 / 다음에 할 일을 순서대로 한 문장씩.
- 예: 「번역 모델이 응답하지 않아 원문만 표시합니다. 녹음은 계속되며, 번역은 종료 후 채워집니다.」
- 기술 용어(ENOSPC 등)는 진단 패널에만 보인다.

## 11. 단축키 (초안)

| 동작 | 제안 |
|---|---|
| 오버레이 표시/숨김 (전역) | `⌘⇧H` |
| 표시 모드 순환 (전역) | `⌘⇧M` |
| 녹음 일시정지/재개 (전역) | `⌘⇧P` |
| 편집기: 재생/정지 | `Space` |
| 편집기: 구간 반복 | `L` |
| 편집기: 분할 / 병합 | `⌘E` / `⌘J` |
| Undo / Redo | `⌘Z` / `⇧⌘Z` |

충돌 가능성이 있어 설정에서 변경할 수 있어야 한다.

## 12. 접근성

키보드만으로 편집기를 쓸 수 있어야 한다. 오버레이 글자 크기·대비를 조절할 수 있어야 한다. 색만으로 상태를 구분하지 않는다 (아이콘 병행).

## 13. 재생 모드 화면 (ADR-006)

진입: 프로젝트 목록의 「재생」, 또는 「SRT 불러오기」.

1. **영상 앱 선택** — 캡처와 같은 앱 단위 선택(Q6). 영상이 재생되는 브라우저·플레이어를 고른다.
2. **듣는 중** — 영상을 재생하면 SubBridge가 소리를 듣고 영상 위치를 찾는다. 오버레이에는 「싱크 찾는 중…」을 작게 표시하고 자막은 아직 띄우지 않는다.
3. **싱크됨 ✓** — 위치를 찾으면 자막이 영상에 맞춰 표시된다. 컨트롤 바에 추정 위치(예: 00:12:34)를 보여 준다.
4. **다시 맞추는 중** — 되감기·건너뛰기로 위치가 바뀌면 자동으로 다시 찾는다.
5. **수동 미세조정** (필요할 때만)
   - 단축키로 ±0.5초 / ±5초 이동
   - 「지금 이 대사에 맞추기」: 자막 목록에서 줄을 고르면 그 줄을 현재 시점으로 지정
   - 자동 싱크 잠금/해제
   - 보정값은 프로젝트에 저장되어 다음 재생에도 쓰인다

오버레이는 §4와 같다 (표시 모드, 스타일, 위치, 단축키, 항상 위, 마우스 통과).
소리가 들리지 않으면(권한·보호된 오디오) 캡처 때와 같은 안내를 보여 주고, **수동 시작·보정**으로 쓸 수 있게 한다.

불러온 SRT의 큐가 두 줄(이중 자막)이면 두 줄 그대로 표시한다. 원문/번역을 분리하지 않는다.
